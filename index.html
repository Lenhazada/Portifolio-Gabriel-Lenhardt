Meus Projetos

Workshop Spring Boot + JPA

API REST para gerenciamento de usuários, produtos, categorias e pedidos, construída com Spring Boot, JPA e Hibernate. O projeto implementa conceitos essenciais do desenvolvimento backend, tais como: arquitetura em camadas, persistência de dados, relacionamentos entre entidades, operações CRUD, tratamento de exceções, entre outros, tudo isso respeitando as boas práticas do desenvolvimento.

DsList

Um aplicativo em Java criado para organizar e apresentar listas de jogos de maneira estruturada. O projeto foi estruturado em camadas, interage de forma eficiente entre o back-end e o banco de dados, e segue boas práticas de desenvolvimento, permitindo operações como listagem, ordenação e consulta de dados. Foi criado com foco em aprendizado de APIs REST, organização de código e modelagem de dados.

Xadrez com Java

Jogo de xadrez em Java,jogado no terminal da IDE, com ênfase na Programação Orientada a Objetos utilizando somente Java com lógica de programação. O projeto coloca em prática todas as regras e movimentos das peças, o controle das jogadas, a captura, o xeque, o xeque-mate, tudo isso com uma estrutura bem organizada para representar o tabuleiro e os elementos do jogo.
